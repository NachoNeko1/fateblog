TypeScript 是 JavaScript 的超集，在 JavaScript 的基础上添加了静态类型系统。它能帮助开发者在编译时捕获错误，提升代码质量和开发效率。

## 为什么选择 TypeScript？

### 类型系统的优势

- ✅ 提前捕获类型错误
- ✅ 更好的 IDE 支持（自动补全、跳转定义）
- ✅ 更强的重构信心
- ✅ 更好的代码文档（类型即文档）
- ✅ 提升团队协作效率

### 对比 JavaScript

```javascript
// JavaScript - 运行时错误
function add(a, b) {
  return a + b;
}

add('hello', 1); // ❌ 'hello1' 不符合预期

// TypeScript - 编译时错误
function add(a: number, b: number): number {
  return a + b;
}

add('hello', 1); // ❌ 编译错误：参数类型不匹配
```

## 基础类型

### 原始类型

```typescript
let name: string = 'John';
let age: number = 25;
let isStudent: boolean = true;
let nothing: null = null;
let undefinedVal: undefined = undefined;
```

### 数组和元组

```typescript
let numbers: number[] = [1, 2, 3];
let names: Array<string> = ['John', 'Jane'];

let tuple: [string, number, boolean] = ['name', 25, true];
let readonlyTuple: readonly string[] = ['a', 'b'];
```

### 枚举

```typescript
enum Direction {
  Up = 'UP',
  Down = 'DOWN',
  Left = 'LEFT',
  Right = 'RIGHT'
}

let direction: Direction = Direction.Up;
```

### 联合类型和交叉类型

```typescript
// 联合类型（OR）
type ID = string | number;
type Status = 'pending' | 'success' | 'error';

// 交叉类型（AND）
type Person = { name: string };
type Employee = { company: string };
type EmployeeInfo = Person & Employee;
```

## 对象和接口

### 接口定义

```typescript
interface User {
  name: string;
  age: number;
  email?: string; // 可选属性
  readonly id: number; // 只读属性
}

let user: User = {
  name: 'John',
  age: 25,
  id: 1
};
```

### 类型别名

```typescript
type User = {
  name: string;
  age: number;
};

type ID = string | number;
```

### 接口继承

```typescript
interface Animal {
  name: string;
  age: number;
}

interface Dog extends Animal {
  breed: string;
  bark(): void;
}
```

## 函数类型

### 函数定义

```typescript
// 完整类型声明
function greet(name: string): string {
  return `Hello, ${name}!`;
}

// 箭头函数
const greet = (name: string): string => `Hello, ${name}!`;

// 函数类型
type MathOperation = (a: number, b: number) => number;
const add: MathOperation = (a, b) => a + b;
```

### 可选参数和默认值

```typescript
function greet(name: string, greeting?: string): string {
  return greeting ? `${greeting}, ${name}!` : `Hello, ${name}!`;
}

function greet(name: string, greeting = 'Hello'): string {
  return `${greeting}, ${name}!`;
}
```

### 剩余参数

```typescript
function sum(...numbers: number[]): number {
  return numbers.reduce((total, num) => total + num, 0);
}
```

## 泛型

### 基本泛型

```typescript
function identity<T>(value: T): T {
  return value;
}

identity('hello'); // T = string
identity(123);     // T = number
identity<boolean>(true); // T = boolean
```

### 泛型接口

```typescript
interface ApiResponse<T> {
  data: T;
  status: number;
  message: string;
}

const response: ApiResponse<User> = {
  data: { name: 'John', age: 25 },
  status: 200,
  message: 'OK'
};
```

### 泛型约束

```typescript
interface HasLength {
  length: number;
}

function logLength<T extends HasLength>(item: T): void {
  console.log(item.length);
}

logLength('hello'); // ✅
logLength(123);     // ❌ 数字没有 length 属性
```

## 类型守卫

### typeof 守卫

```typescript
function isString(value: unknown): value is string {
  return typeof value === 'string';
}

function process(value: unknown) {
  if (isString(value)) {
    // value 被推断为 string
    console.log(value.toUpperCase());
  }
}
```

### instanceof 守卫

```typescript
class User {
  constructor(public name: string) {}
}

class Admin extends User {
  constructor(public role: string) {
    super('Admin');
  }
}

function checkAccess(user: User | Admin): string {
  if (user instanceof Admin) {
    return 'Admin access';
  }
  return 'User access';
}
```

## 高级类型

### 映射类型

```typescript
type Stringify<T> = {
  [P in keyof T]: string;
};

type User = { name: string; age: number };
type StringifiedUser = Stringify<User>;
// { name: string; age: string; }
```

### 条件类型

```typescript
type IsString<T> = T extends string ? true : false;

type A = IsString<'hello'>; // true
type B = IsString<number>;  // false
```

## 类型操作符

```typescript
// keyof - 获取对象的键类型
type User = { name: string; age: number };
type UserKeys = keyof User; // 'name' | 'age'

// typeof - 获取变量的类型
let user = { name: 'John', age: 25 };
type UserType = typeof user;

// in - 属性存在检查
type HasName = 'name' in { name: string }; // true
```

## 实用技巧

### as const

```typescript
const directions = {
  Up: 'UP',
  Down: 'DOWN'
} as const;

// directions 的类型为 readonly { Up: 'UP'; Down: 'DOWN'; }
// 而不是 { Up: string; Down: string; }
```

### satisfies 操作符

```typescript
const config = {
  name: 'MyApp',
  version: '1.0.0'
} satisfies { name: string; version: string };

// config 的类型为 { name: string; version: string; }
// 但保留了具体的字面量类型
```

## 总结

TypeScript 通过静态类型系统为 JavaScript 提供了强大的工具。掌握 TypeScript 不仅能提升代码质量，还能让大型项目的维护变得更加容易。建议从简单的类型开始，逐步深入学习高级类型特性。

> "类型不是约束，而是自由的保障。"
