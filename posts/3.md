现代 CSS 提供了强大的布局工具，包括 Flexbox 和 Grid。掌握这些技术可以让你的网页设计更加灵活和响应式。本文将深入探讨这些现代布局技巧。

## Flexbox 弹性布局

### 基本概念

Flexbox 是一种一维布局模型，适合处理行或列方向的布局。

```css
.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 20px;
}
```

### 常用属性

- `flex-direction`：设置主轴方向
- `justify-content`：主轴对齐
- `align-items`：交叉轴对齐
- `flex-wrap`：是否换行
- `gap`：间距

### Flex 属性

`flex` 是 `flex-grow`、`flex-shrink` 和 `flex-basis` 的简写：

```css
.item {
  flex: 1; /* 等分空间 */
  flex: 0 0 200px; /* 固定宽度 */
  flex: 2 1 300px; /* 扩展2倍，收缩1倍，基准300px */
}
```

## Grid 网格布局

### 基本概念

Grid 是一种二维布局模型，可以同时控制行和列。

```css
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  grid-template-rows: auto;
  gap: 20px;
}
```

### 常用属性

- `grid-template-columns`：定义列
- `grid-template-rows`：定义行
- `grid-column`：跨越列
- `grid-row`：跨越行
- `grid-gap`：间距

### 常用网格模板

```css
/* 等宽列 */
grid-template-columns: repeat(auto-fill, minmax(250px, 1fr));

/* 经典三栏布局 */
grid-template-columns: 1fr 3fr 1fr;

/* 圣杯布局 */
grid-template-columns: 250px 1fr 300px;
grid-template-rows: auto 1fr auto;
```

## Flexbox vs Grid

### 使用场景对比

| 特性 | Flexbox | Grid |
|------|---------|------|
| 维度 | 一维 | 二维 |
| 布局方向 | 行或列 | 行和列 |
| 内容控制 | 内容决定布局 | 布局决定内容 |
| 适用场景 | 导航栏、按钮组 | 整体页面布局 |

### 何时使用 Flexbox

- 导航栏、工具栏
- 按钮组、标签组
- 卡片组件内部布局
- 一维对齐需求

### 何时使用 Grid

- 整体页面布局
- 卡片网格
- 复杂的多维布局
- 需要精确控制位置的场景

## 现代 CSS 新特性

### CSS 自定义属性（变量）

```css
:root {
  --primary-color: #6c5ce7;
  --spacing: 20px;
}

.button {
  color: var(--primary-color);
  padding: var(--spacing);
}
```

### 逻辑属性

逻辑属性可以让样式支持多语言布局：

```css
.element {
  margin-inline-start: 20px; /* 对应 margin-left（LTR）或 margin-right（RTL） */
  padding-block: 10px;
}
```

### 容器查询

容器查询允许根据父容器大小调整样式，比媒体查询更灵活：

```css
@container (min-width: 400px) {
  .card {
    display: flex;
  }
}
```

## 最佳实践

- 优先使用 Flexbox 处理组件内部布局
- 使用 Grid 处理页面整体布局
- 结合使用两种布局方式
- 使用 CSS 变量提高可维护性
- 测试响应式效果

## 总结

现代 CSS 布局工具非常强大，合理运用 Flexbox 和 Grid 可以创建出精美且灵活的网页布局。掌握这些技巧，让你的网页设计更上一层楼！
